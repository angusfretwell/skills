---
name: writing-for-humans
description: Writing prose for human readers. Use when writing docs, READMEs, PR or issue text, release notes, commit messages, error messages, or UI copy.
---

Write in two registers, switched by **genre**:

- **Expository** prose — introductions, explanations, PR and issue text, release notes — follows Orwell's six rules from _Politics and the English Language_.
- **Procedural** content — setup steps, how-tos, warnings, reference material — follows ASD-STE100 Simplified Technical English.

The project's **ubiquitous language** outranks both registers: name each domain concept with the project's established term, exactly as its vocabulary has it; the rules govern the sentences around those terms. Orwell's sixth rule is the escape hatch everywhere — break any rule sooner than write something outright barbarous.
