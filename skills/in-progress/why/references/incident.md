# Incident brief

A cross-cutting hunt, appended to every investigator when the anchor flags the target **defensive**. Incidents motivate defensive code ("we added this check after the outage"), so search your own source for incident history in the window around the dates the target was added, and fetch any postmortem in full: its action items tie to code changes. When one incident ID threads through several sources, record your own link to it, so the synthesizer can join them.

Done when the window has been searched for incident history in your source and those queries recorded under What I searched, hits or none.
