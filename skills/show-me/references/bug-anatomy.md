# Bug anatomy

Past tense for the bug, present tense for the fix.

A section per point:

1. **The symptom** — what the user saw; a repro storyboard of captures when the bug is visible on screen.
2. **The mechanism** — a diagram of the failing path: the real states, and the branch where behavior diverged.
3. **The fix** — what changed, as prose with linked code references; the diagram's failing edge redrawn or annotated.
4. **The proof** — the same flow after the fix: a capture, or the passing test's output.
